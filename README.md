# אפליקציית תרגול אנגלית לילדים

זוהי אפליקציית רשת פשוטה ואינטראקטיבית שנועדה לעזור לילדים צעירים לתרגל אוצר מילים באנגלית בצורה מהנה.

## ✨ תכונות

- **משחק אינטראקטיבי**: האפליקציה מציגה משחק "איפה החיה?" כדי למשוך את תשומת הלב של הילד.
- **משוב קולי**: האפליקציה משתמשת בקול כדי לשאול שאלות ולתת משוב, מה שהופך אותה למתאימה לילדים שאינם יודעים לקרוא.
- **משוב ויזואלי**: בנוסף לקול, האפליקציה מציגה סימנים ויזואליים (✅ או ❌) לתשובות נכונות או שגויות.
- **למידה מטעויות**: כאשר נבחרת תשובה שגויה, האפליקציה אומרת את שם החיה שנבחרה כדי לחזק את הלמידה.
- **אין צורך בהתקנה**: האפליקציה פועלת ישירות מהדפדפן ללא צורך בהתקנה או בשרת.

## 🚀 איך להשתמש

1.  ודאו שיש לכם את כל קבצי הפרויקט (`index.html`, `style.css`, `script.js`).
2.  מצאו את הקובץ `index.html`.
3.  פתחו את הקובץ `index.html` בכל דפדפן מודרני (כמו גוגל כרום, פיירפוקס או ספארי).
4.  המשחק יתחיל באופן אוטומטי!

## ✏️ איך להוסיף מילים חדשות (להורים)

ניתן בקלות להוסיף עוד חיות או חפצים למשחק.

1.  פתחו את הקובץ `script.js` בעורך טקסט.
2.  מצאו את החלק שמתחיל ב-`const vocabulary = {`.
3.  הוסיפו שורה חדשה בפורמט הבא:
    ```javascript
    'EnglishWord': 'https://link-to-image.png',
    ```
    לדוגמה, כדי להוסיף "צפרדע" (Frog), תוסיפו:
    ```javascript
    'Frog': 'https://some-website.com/frog-image.png',
    ```
4.  שמרו את הקובץ, וזהו! המילה החדשה תופיע במשחק באופן אקראי.
